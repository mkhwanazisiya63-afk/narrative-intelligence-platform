# Narrative Intelligence Platform Taxonomy

## Purpose

The taxonomy defines the controlled vocabulary used to annotate media works.

A controlled vocabulary ensures that all media entries use consistent terminology,
making search, recommendation, and analysis more reliable.

---

# Themes

Definition:

A recurring central idea explored throughout a narrative.

Examples:

- Identity
- Revenge
- Justice
- Survival
- Love
- Memory
- Freedom
- Sacrifice

---

# Emotions

Definition:

The dominant emotional experiences intended for the audience.

Examples:

- Fear
- Hope
- Curiosity
- Sadness
- Wonder
- Anxiety

---

# Narrative Structures

Definition:

The storytelling framework used by a narrative.

Examples:

- Hero's Journey
- Time Loop
- Anti-Hero
- Redemption Arc
- Coming of Age

---

# Character Archetypes

Definition:

Recurring character patterns commonly found in stories.

Examples:

- Mentor
- Shadow
- Trickster
- Chosen One
- Fallen Hero
